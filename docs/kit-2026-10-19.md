# بسته‌ی کار استوک‌لند — هفته‌ی ۱۹ تا ۲۵ اکتبر ۲۰۲۶

جاهایی که `{{...}}` دارند را خودتان پر کنید (قیمت، ساعت کاری، گارانتی). هیچ عدد یا قولی از خودم نساختم.

## ۱) جواب خودکار دایرکت (Meta Business Suite ← Inbox ← Automations)

### Instant reply — جواب فوری اولین پیام
```
سلام، به استوک‌لند خوش اومدی 🍏
پیامت رسید و تا {{چند دقیقه/ساعت}} دیگه خودمون جواب می‌دیم.
برای سریع‌تر شدن کار، مدل آیفون و چیزی که می‌خوای (خرید، فروش یا معاوضه) رو همین‌جا بنویس.
```

### Away message — خارج از ساعت کاری
ساعت کاری را در Automations روی `{{ساعت کاری}}` تنظیم کنید.
```
سلام، الان خارج از ساعت کاری هستیم ({{ساعت کاری}}).
پیامت رو بذار، اول وقت کاری جواب می‌دیم 🍏
برای فوری: {{شماره یا واتساپ}}
```

درصد باتری: Settings ← Battery ← Battery Health

### Custom keywords — جواب کلمه‌ی کلیدی
کلمه:
```
قیمت
```
جواب:
```
قیمت‌ها هر روز با بازار عوض می‌شه، برای همین مدل و حافظه‌ی مدنظرت رو بفرست تا قیمت امروز رو بدیم 🍏
```
کلمه:
```
اصل
```
جواب (برای ریلز «تشخیص آیفون اصل»، پایین‌تر):
```
این هم راهنمای کامل 👇
۱. Settings ← General ← About ← Model Number: حرف اول M یعنی نو، F یعنی بازسازی‌شده (ریفربیش)، N یعنی تعویضی، P یعنی شخصی‌سازی‌شده.
۲. Settings ← General ← About ← Parts and Service History: قطعه‌ی غیراصل یا تعمیر شده اینجا نشون داده می‌شه (iPhone XS به بعد، iOS 15.2 یا جدیدتر).
۳. Settings ← Battery ← Battery Health: درصد سلامت باتری.
قبل از خرید هر آیفون دست دوم این سه تا رو چک کن. سؤالی بود همین‌جا بپرس.
```
کلمه:
```
باتری
```
جواب (برای ریلز «قفل شارژ روی ۸۰٪»):
```
راهنمای سلامت باتری آیفون 🔋
۱. درصد سلامت: Settings ← Battery ← Battery Health. زیر ۸۰٪ یعنی وقت تعویض باتریه.
۲. محدودیت شارژ: Settings ← Battery ← Charging ← 80% Limit (آیفون ۱۵ به بعد). برای مدل‌های قبلی Optimized Battery Charging رو روشن کن.
۳. موقع شارژ گوشی رو داخل کاور ضخیم یا زیر آفتاب داغ نکن.
سؤالی بود همین‌جا بپرس 🍏
```

## ۳) برنامه‌ی محتوای هفته (۶ ریلز)
قاعده‌ها از تحلیل: مشکل مشخص در ۲ ثانیه‌ی اول، یک CTA، کپشن کوتاه با مسیر دقیق.
ساعت: داده‌ی قطعی نداریم؛ این هفته همه را **یک ساعت ثابت** بگذارید ({{ساعت انتخابی}}) تا هفته‌ی بعد مقایسه کنیم.

### شنبه — تشخیص آیفون اصل قبل از خرید (CTA کلمه‌ی کلیدی، مثل پست کد پستی)
- **هوک (۰ تا ۲ ثانیه):** «قبل از خرید آیفون دست دوم این سه تا رو چک نکنی، ضرر کردی.»
- **متن روی صفحه:** «اصل یا تقلبی؟ ۳ چک ۳۰ ثانیه‌ای»
- **ساختار:** ۱) Model Number و معنی M/F/N/P ← ۲) Parts and Service History ← ۳) Battery Health ← جمع‌بندی.
- **CTA آخر ویدیو:** «کلمه‌ی اصل رو کامنت کن، راهنمای کامل رو برات دایرکت می‌کنم.»
- **کپشن:**
```
قبل از خرید آیفون دست دوم این ۳ تا رو حتماً چک کن 👇
کلمه «اصل» رو کامنت کن تا راهنمای کامل رو برات بفرستم 🍏
#آیفون #خرید_آیفون #آیفون_دست_دوم #ترفند_آیفون #استوک_لند
```

### یکشنبه — رمز وای‌فای ذخیره‌شده رو ببین
- **هوک:** «رمز وای‌فای خونه یادت رفته؟ آیفونت بلده.»
- **مسیر:** Settings ← Wi-Fi ← (i) کنار شبکه ← Password (iOS 16 به بعد) ← با Face ID باز می‌شه.
- **CTA:** «بفرست برای کسی که همیشه رمز وای‌فای رو ازت می‌پرسه.»
- **کپشن:**
```
رمز وای‌فای رو یادت رفته؟ از خود آیفون ببینش 👇
Settings ← Wi-Fi ← (i) ← Password
بفرست برای کسی که همیشه رمز رو ازت می‌پرسه 😅
#آیفون #ترفند_آیفون #وای_فای #iphone
```

### دوشنبه — آیفونت چند می‌ارزه؟ (جذب مشتری؛ پست مشابهش ۴۰۲ کامنت گرفت)
- **هوک:** «آیفون ۱۳ تا ۱۷ داری؟ بگو چند می‌ارزه.» (چند گوشی واقعی فروشگاه جلوی دوربین)
- **ساختار:** ۳ چیزی که قیمت رو تعیین می‌کنه: حافظه، درصد باتری، بدنه/تعمیر.
- **CTA:** «مدل و حافظه‌ی گوشیتو کامنت کن، قیمت امروزش رو بهت می‌گم.»
- **کار مهم:** به **همه‌ی** کامنت‌ها جواب بدید و پیشنهاد معاوضه در دایرکت بدید؛ این‌ها مشتری‌اند.
- **کپشن:**
```
آیفونت امروز چند می‌ارزه؟ 🤔
مدل + حافظه رو کامنت کن، قیمت امروزش رو بهت می‌گم 🍏
خرید، فروش و معاوضه: دایرکت
#قیمت_آیفون #معاوضه_آیفون #آیفون #استوک_لند
```

### سه‌شنبه — حافظه‌ت پر شده؟ بدون پاک کردن عکس خالیش کن
- **هوک:** «Storage Full؟ قبل از پاک کردن عکس‌هات اینو ببین.»
- **مسیر:** Settings ← General ← iPhone Storage ← Offload Unused Apps (برنامه پاک می‌شه ولی اطلاعاتش می‌مونه) + بخش Recently Deleted آلبوم‌ها.
- **CTA:** «ذخیره کن، دفعه‌ی بعد که حافظه پر شد لازمت میشه.»
- **کپشن:**
```
حافظه‌ی آیفونت پر شده؟ بدون پاک کردن عکس‌ها جا باز کن 👇
Settings ← General ← iPhone Storage ← Offload Unused Apps
📌 ذخیره کن، دیر پیداش می‌کنی
#آیفون #حافظه_آیفون #ترفند_آیفون #iphone
```

### چهارشنبه — اگه آیفونت دزدیده بشه رمزت هم کافی نیست
- **هوک:** «دزد رمز آیفونتو بدونه، همه‌ی حساب‌هات رفته. مگر اینکه اینو روشن کنی.»
- **مسیر:** Settings ← Face ID & Passcode ← Stolen Device Protection ← روشن (iOS 17.3 به بعد).
- **CTA:** «بفرست برای خانواده‌ت؛ ۱۰ ثانیه کار داره.»
- **کپشن:**
```
این گزینه رو همین الان روشن کن 🔒
Settings ← Face ID & Passcode ← Stolen Device Protection
بفرست برای خانواده؛ ۱۰ ثانیه کار داره
#امنیت_آیفون #آیفون #ترفند_آیفون #iphone
```

### پنجشنبه — شارژ آیفون رو روی ۸۰٪ قفل کن (باتری دیرتر خراب می‌شه)
- **هوک:** «آیفونت هر شب تا ۱۰۰٪ شارژ می‌شه؟ باتریت داره زودتر پیر می‌شه.»
- **مسیر:** Settings ← Battery ← Charging ← 80% Limit (iPhone 15 به بعد) / برای مدل‌های قدیمی‌تر: Optimized Battery Charging.
- **CTA:** «کلمه‌ی باتری رو کامنت کن تا راهنمای سلامت باتری رو بفرستم.»
- **کپشن:**
```
باتری آیفونت رو زودتر پیر نکن 🔋
Settings ← Battery ← Charging
«باتری» رو کامنت کن تا راهنمای کامل رو بفرستم
#باتری_آیفون #آیفون #ترفند_آیفون #iphone
```
(برای این ریلز یک keyword دیگر به نام «باتری» در Automations بسازید.)

### استوری‌ها (هر روز ۲ تا ۳ تا)
- صبح: پشت صحنه‌ی فروشگاه یا گوشی جدید رسیده + استیکر **Question**: «دنبال چه مدلی هستی؟»
- عصر: ریلز همان روز را به استوری بفرستید + استیکر **Poll** مرتبط («این تنظیم رو داشتی؟ آره/نه»).
- یک روز در میان: استیکر **Link** یا «دایرکت بده» برای خرید/معاوضه.

## ۴) دستور وایرال‌یابی برای Claude در Chrome (هفته‌ای یک بار، روی کامپیوتر)
اول در Chrome وارد instagram.com شوید، بعد این را در پنل Claude بفرستید:
```
با همین Chrome که وارد اینستاگرام هستم، این پیج‌ها رو یکی‌یکی باز کن: {{۸ تا ۱۰ آیدی پیج آیفون/موبایل فارسی}}. از هر پیج ۱۲ ریلز آخر رو ببین و تعداد بازدید هر کدوم رو بنویس. برای هر پیج میانه‌ی بازدید رو حساب کن و ریلزهایی که بیشتر از ۳ برابر میانه‌ی همون پیج دیده شدن رو جدا کن. برای هر کدوم بنویس: آیدی، بازدید، چند برابر میانه، هوک ۲ ثانیه‌ی اول (دقیق همون کلمات)، موضوع، و اینکه CTA داشته یا نه. آخرش یک جدول فارسی بده و ۵ ایده‌ی ریلز برای پیج استوک‌لند پیشنهاد کن که از همین فرمول‌ها استفاده کنه ولی محتواش کپی نباشه. هیچ لایک، فالو، کامنت یا پیامی نذار و آروم و با سرعت عادی صفحه‌ها رو باز کن.
```
اگر پیج رقیب نمی‌شناسید، اول این را بفرستید:
```
توی اینستاگرام هشتگ‌های #ترفند_آیفون و #آیفون رو ببین و ۱۰ پیج فارسی‌زبان فعال در آموزش یا فروش آیفون که بین ۵ هزار تا ۲۰۰ هزار فالوور دارن پیدا کن. فقط اسم و تعداد فالوورشون رو بنویس؛ هیچ کاری روی پیج‌ها انجام نده.
```
