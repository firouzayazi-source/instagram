# مدل هوش مصنوعی محلی روی سرور (آزمایشی)

هدف: وقتی کلید OpenAI/Gemini نیست یا سرویس‌های خارجی در دسترس نیستند، یک مدل کوچک روی خود سرور سؤال‌هایی را که موتور آفلاین نفهمید جواب بدهد.

## آنچه در کد آماده است
- پنل از قبل «سرویس دلخواه (سازگار با OpenAI)» دارد (`app/ai.py`، provider `custom`). آدرس محلی `http://127.0.0.1:…` یا `http://localhost:…` پذیرفته می‌شود و کلید لازم ندارد.
- ابزار سنجش `tools/local_llm_check.py`: رم و هسته‌ها، فهرست مدل‌ها، سه سؤال فارسی نمونه با زمان جواب. فقط می‌خواند. چیزی نصب یا تنظیم نمی‌کند.

## آنچه هنوز تصمیم صاحب سرور است (اجرا نشده)
نصب یک سرویس تازه روی سرور (مثل Ollama) کاری بیرون از پوشه‌ی `/opt/igbot` است. برای همین بدون تأیید صاحب سرور انجام نمی‌شود. ملاحظه‌ها:
- **منابع:** مدل ۱.۵ تا ۳ میلیارد پارامتری (مثل `qwen2.5:3b`، که فارسی را نسبتاً می‌فهمد) حدود ۲ تا ۴ گیگ رم می‌خواهد. روی پردازنده‌ی بدون GPU هر جواب چند ثانیه تا بیش از ده ثانیه طول می‌کشد. سرویس‌های دیگر سرور نباید کند شوند.
- **دانلود:** ممکن است سایت Ollama و مخزن مدل‌ها از سرور ایران باز نشود. در آن صورت فایل مدل باید از جای دیگری آورده شود.
- **کیفیت:** مدل کوچک ممکن است حرف بی‌پایه بزند. قاعده‌ی «هیچ قیمت یا سیاستی از خودت نساز» در دستور سیستمی پنل هست، ولی جواب‌ها اول با `tools/local_llm_check.py` با چشم سنجیده شوند.
- **امنیت:** سرویس فقط روی 127.0.0.1 گوش بدهد، نه روی اینترنت.

## اگر صاحب سرور تأیید کرد
۱. Ollama را طبق راهنمای رسمی خودش نصب کنید و یک مدل بگیرید (مثلاً `qwen2.5:3b`).
۲. سنجش:
```
cd /opt/igbot && sudo -u igbot .venv/bin/python tools/local_llm_check.py --url http://127.0.0.1:11434/v1
```
۳. اگر سرعت و کیفیت قابل قبول بود: پنل ← هوش مصنوعی ← «سرویس دلخواه»، با آدرس `http://127.0.0.1:11434/v1` و نام همان مدل.
